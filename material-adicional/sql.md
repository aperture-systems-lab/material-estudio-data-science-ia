# SQL — Material adicional

- [jonmircha — Curso de SQL](https://www.youtube.com/watch?v=UAuZvxPTi58) `Video` - `Español`

  Curso completo de SQL en un solo video. *Recomendado por Datogami.*

- [freeCodeCamp Español — SQL desde cero](https://www.youtube.com/@freeCodeCampEspanol) `Video` - `Español`

  Cursos completos de SQL en español. *Recomendado por Datogami.*

- [Luke Barousse — SQL for Data Analytics](https://www.lukebarousse.com/sql) `Curso` - `Inglés`

  Curso gratuito de SQL enfocado a analítica. También en [YouTube](https://www.youtube.com/@LukeBarousse). *Recomendado por Datogami.*

- [TechTFQ — SQL Avanzado](https://www.youtube.com/@techTFQ) `Video` - `Inglés`

  Window functions, CTEs y optimización de consultas. *Recomendado por Datogami.*

- [Data with Baraa — Window Functions](https://www.youtube.com/@DataWithBaraa) `Video` - `Inglés`

  Serie dedicada a las funciones de ventana, uno de los temas clave en entrevistas. *Recomendado por Datogami.*

- [LeetCode — Database](https://leetcode.com/problemset/database/) `Sitio` - `Inglés`

  Ejercicios de SQL del tipo que aparece en entrevistas técnicas. *Recomendado por Datogami.*

- [SQLiteOnline](https://sqliteonline.com/) `Sitio`

  Entorno SQL en el navegador, sin instalar nada. *Recomendado por Datogami.*

- [Use The Index, Luke!](https://use-the-index-luke.com/) `Sitio` - `Inglés`

  Guía sobre índices y rendimiento de consultas SQL. *Recomendado por Datogami.*

- [Explain Depesz](https://explain.depesz.com/) `Sitio` - `Inglés`

  Herramienta para visualizar y entender el resultado de un `EXPLAIN` en PostgreSQL. *Recomendado por Datogami.*

- [Documentación oficial de PostgreSQL](https://www.postgresql.org/docs/current/) `Sitio` - `Inglés`

  Referencia oficial. Especialmente útil la página de [EXPLAIN](https://www.postgresql.org/docs/current/sql-explain.html). *Recomendado por Datogami.*

- [W3Schools SQL](https://www.w3schools.com/sql/) `Sitio` - `Inglés`

  Referencia rápida para consultar la sintaxis de cualquier sentencia. *Recomendado por Datogami.*

- [AprendeSQL](https://www.aprendesql.dev/) `Sitio` - `Español`

  Curso gratuito y práctico de SQL con certificado.
