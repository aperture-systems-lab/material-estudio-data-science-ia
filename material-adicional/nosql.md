# NoSQL — Material adicional

- [Pontia Tech](https://pontia.tech/) `Sitio` - `Español`

  Tutoriales en español. Busca *Tutorial MongoDB en español*. *Recomendado por Datogami.*

- [DataCamp — Tutorial NoSQL](https://www.datacamp.com/es/tutorial/nosql-tutorial) `Sitio` - `Español`

  Introducción a NoSQL con ejemplos prácticos. *Recomendado por Datogami.*

- [freeCodeCamp — MongoDB Crash Course](https://www.youtube.com/@freecodecamp) `Video` - `Inglés`

  Introducción rápida y práctica a MongoDB. *Recomendado por Datogami.*

- [MongoDB Atlas](https://www.mongodb.com/atlas) `Sitio`

  Clúster gratuito en la nube para practicar sin instalar nada. *Recomendado por Datogami.*

- [Redis — Try Free](https://redis.io/try-free/) `Sitio`

  Instancia gratuita de Redis para experimentar con bases de datos clave-valor. *Recomendado por Datogami.*

- [Neo4j GraphAcademy](https://graphacademy.neo4j.com/) `Curso` - `Inglés`

  Cursos gratuitos oficiales sobre bases de datos de grafos. *Recomendado por Datogami.*

- [Seven Databases in Seven Weeks](https://www.oreilly.com/library/view/seven-databases-in/9781680505962/) `Libro` - `Inglés`

  Recorre Redis, Neo4j, MongoDB, HBase, CouchDB, Postgres y DynamoDB. *Recomendado por Datogami.*

- [ScyllaDB — CAP Theorem](https://www.scylladb.com/glossary/cap-theorem/) `Sitio` - `Inglés`

  Explicación clara del teorema CAP, fundamental para entender los sistemas distribuidos. *Recomendado por Datogami.*
