# Python — Material adicional

- [Píldoras Informáticas — Curso de Python](https://www.youtube.com/@pildorasinformaticas) `Video` - `Español`

  Curso muy estructurado y didáctico en más de 70 videos cortos. Ideal para aprender paso a paso. *Recomendado por Datogami.*

- [Código Facilito](https://codigofacilito.com/) `Curso` - `Español`

  Plataforma hispanohablante con cursos de Python gratuitos y de pago, muy bien valorados. También tienen [canal de YouTube](https://www.youtube.com/@codigofacilito). *Recomendado por Datogami.*

- [learnpython.org en español](https://www.learnpython.org/es/) `Sitio` - `Español`

  Tutorial interactivo para practicar Python directamente en el navegador. *Recomendado por Datogami.*

- [Real Python](https://realpython.com/) `Sitio` - `Inglés`

  Artículos y tutoriales de gran calidad sobre prácticamente cualquier tema de Python. *Recomendado por Datogami.*

- [Curso Intensivo de Python — Eric Matthes](https://www.amazon.es/dp/8441549249) `Libro` - `Español`

  Libro muy bien traducido al español. Cubre fundamentos y proyectos prácticos, ampliamente recomendado como primer libro. *Recomendado por Datogami.*

- [Python NumPy Tutorial for Beginners](https://youtu.be/QUT1VHiLmmI) `Video` - `Inglés`

  Tutorial introductorio a NumPy, una de las principales librerías de Python para computación numérica y análisis de datos.

- [Google Colab](https://colab.research.google.com/) `Sitio`

  Entorno de notebooks en la nube: no necesitas instalar nada y puedes ejecutar código Python desde el navegador. *Recomendado por Datogami.*

- [PyPI](https://pypi.org/) `Sitio` - `Inglés`

  El repositorio oficial de paquetes de Python, la fuente de todo lo que instalas con `pip`. *Recomendado por Datogami.*

- [Scikit-Learn User Guide](https://scikit-learn.org/stable/user_guide.html) `Sitio` - `Inglés`

  Guía de usuario de la librería de Machine Learning más usada en Python. Sirve tanto de manual como de repaso teórico. *Recomendado por Datogami.*
